# Bundled OCR language data

Project code is licensed under MIT; see `LICENSE`. The bundled language data
and third-party dependencies retain their respective licenses below.

`dist/tessdata/eng.traineddata.gz` and `deu.traineddata.gz` are unmodified
compressed language data from `@tesseract.js-data/eng@1.0.0` and
`@tesseract.js-data/deu@1.0.0` (`4.0.0_best_int`).

Source: https://github.com/naptha/tessdata (Tesseract.js language data).
The upstream language data is distributed under Apache License 2.0;
a copy is included in `licenses/Apache-2.0.txt`.

Other dependencies, including Tesseract.js, PDF.js and @napi-rs/canvas, are
installed by npm and retain their respective licenses and notices.
